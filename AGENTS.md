# VitalAge — Agent Instructions

Biological age from NHANES blood biomarkers (97K raw rows). Python + pandas/numpy/scipy + scikit-learn + jupyter. No lint/typecheck/CI workflows — `requirements.txt` only.


## Architecture

- `config.yaml` — source of truth for paths, 12 final columns, biological clip ranges, age bounds. `src/data/load_data.py:load_config()` adds `_base_dir` and `_resolve_path()` resolves relatives to config dir.
- `src/data/clean_blood_data.py:run_cleaning_pipeline()` — select_columns → filter_age_range(18-80 inclusive) → clip_outliers → dropna → `data/processed/bioage_final_clean.csv` (Age + 12 biomarkers). `select_columns` drops anything in `drop_high_missing`/`drop_duplicate` even if listed in `secondary`.
- `src/features/build_features.py:build_features()` — reads clean CSV, `np.log1p` on `SKEWED_FEATURES` present & >=0 (effectively `CRP,LBXSAPSI,LBXWBCSI,LBXGH`; `LBXTR` in list but already dropped), adds `age_group` bins `[0,18,30,45,60,75,100]` → `data/processed/bioage_model_ready.csv` (13+5 cols).
- `src/models/blood/` — `train_ridge.py`, `train_xgboost.py`, `train_LightGBM.py`, `calibrated_xgboost.py`, `tune_xgboost.py` (real entrypoints). `phenoage_formula.py`, `train_model.py`, `evaluate_model.py` are empty stubs. `src/models/face/` + `fusion/` and `src/explainability/shap_utils.py` also stubs.
- `notebooks/blood/` — `01_data_overview` → `02_missingness_and_cleaning` → `03_eda` → `04_feature_selection` (executed by `run_pipeline.py:46-54`), plus `05_model_comparison.ipynb` and `05_model_comparison_LightGBM.ipynb` (NOT run by pipeline).
- `app/` — `streamlit_app.py` + `pdf_parser.py` stubs; `reports/figures/*.png` (13+ charts) generated by notebooks.

## Data & Gotchas

- All `*.csv`/`*.xpt` and `data/raw/`, `data/interim/`, `data/processed/`, `models/*.pkl|*.h5|*.json` are gitignored — outputs never appear in `git status`. Must have `data/raw/blood_age_mega_raw.csv` locally to regenerate; `data/processed/*.csv` currently ~20K×13 / ~20K×18 (docs say 22,094 — varies with pipeline).
- Age filtering is inclusive 18–80 (`src/data/clean_blood_data.py:62` `>=`/`<=`); 1106 rows at exactly 80 remain in current clean CSV — contradicts `PROJECT_REFERENCE.md` claim that age-80 spike is dropped.
- `config.yaml:columns.secondary` lists 5 (`LBXGH,LBDLDL,LBDHDD,LBXTR,LBXTC`) but `drop_high_missing` removes `LBDLDL`/`LBXTR` (70% missing), so only `LBXGH,LBDHDD,LBXTC` survive. `LBXGLU` kept despite 69% missing (required PhenoAge core). Duplicate alt-codes `LBXSCH`/`LBXSGL` also dropped.
- Outlier handling is `clip` to `outlier_ranges`, not drop. `SKEWED_FEATURES` log transforms skip missing/negative columns silently.
- No `opencode.json`, no task runner, no `.github/workflows`. Branch is `vinita` (origin `main`); `PROJECT_REFERENCE.md` is the detailed design doc if needed.
